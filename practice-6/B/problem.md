
Правильные скобочные последовательности

Правильная скобочная последовательность (ПСП) — это строка из символов ( и ), в любом префиксе которой закрывающих скобок не больше, чем открывающих, а всего открывающих и закрывающих скобок поровну.

По заданному n выведите все ПСП, состоящие ровно из n пар скобок.
Входные данные

Одно целое число n — количество пар скобок (1 ≤ n ≤ 10).
Выходные данные

Все ПСП из n пар скобок, по одной в строке, в лексикографическом порядке. Считайте, что символ ( меньше символа ).
Примеры

вход:
1
выход:
()

вход:
2
выход:
(())
()()

вход:
3
выход:
((()))
(()())
(())()
()(())
()()()

Замечания

Строку удобно строить слева направо рекурсивно. На очередную позицию можно поставить (, если открывающих скобок пока меньше n, и ) — если закрывающих меньше, чем уже поставленных открывающих. При таком переборе неправильные строки не появляются вовсе, а обрезка ветвей экономит время.

Чтобы порядок вывода был лексикографическим, сначала пробуйте поставить (, и только потом ).

Строк может быть много: при n = 10 их 16 796.
