
Ханойские башни

Есть три стержня, обозначенных A, B и C. На стержне A лежат n дисков разного размера: снизу самый большой, сверху самый маленький.

За один ход разрешается снять верхний диск с любого стержня и положить его на другой стержень. Класть больший диск на меньший нельзя.

Перенесите все диски со стержня A на стержень C за минимальное число ходов и выведите эту последовательность ходов.
Входные данные

Одно целое число n — количество дисков (1 ≤ n ≤ 16).
Выходные данные

2^n − 1 строк — ходы в порядке выполнения. Каждая строка имеет вид X -> Y, где X — стержень, с которого снимают диск, а Y — стержень, на который его кладут. Стержни обозначаются заглавными латинскими буквами A, B, C.
Примеры

вход:
1
выход:
A -> C

вход:
2
выход:
A -> B
A -> C
B -> C

вход:
3
выход:
A -> C
A -> B
C -> B
A -> C
B -> A
B -> C
A -> C

Замечания

Минимальное число ходов равно 2^n − 1, и последовательность ходов такой длины единственна — проверяться будет именно она.

Сведите задачу к меньшей. Чтобы перенести n дисков с A на C, сначала перенесите верхние n − 1 дисков на промежуточный стержень B, затем перенесите самый большой диск с A на C, затем перенесите n − 1 дисков с B на C. База рекурсии — n = 0: делать ничего не нужно.
