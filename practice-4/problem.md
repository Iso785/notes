
Удаление комментариев

Дан файл input.txt с исходным текстом программы на C. Удали из него все комментарии, а остальной текст без изменений запиши в файл output.txt.

В C два вида комментариев.

    /* … */ начинается с /* и заканчивается первым следующим */. Может занимать несколько строк. Вложенных комментариев нет: в /* a /* b */ c */ комментарий — это /* a /* b */, а c */ — уже код. Такой комментарий замени одним пробелом: так делает и компилятор, поэтому int/**/x превращается в int x, а не в intx.
    // … продолжается до конца строки. Перевод строки в комментарий не входит, его надо оставить.

Внутри строковых "…" и символьных '…' констант комментариев не бывает: "/* не комментарий */" выводится как есть. В константах встречается экранирование обратным слешем: "\"", '\'', "\\".

Внутри комментариев кавычки ничего не значат: // don't — комментарий целиком, апостроф в нём не открывает символьную константу.
Входные данные

Файл input.txt в текущем каталоге. Стандартный ввод пуст: читать надо из файла. Размер файла — от 1 до 1 000 000 байт, число и длина строк отдельно не ограничены.

Текст не обязан компилироваться, но гарантируется следующее:

    все строковые и символьные константы и все комментарии /* */ закрыты;
    константы не переносятся на следующую строку;
    ни одна строка не заканчивается обратным слешем \;
    текст состоит только из печатных символов ASCII (коды 32–126), табуляций и переводов строк \n, без \r и без кириллицы.

Выходные данные

Текст без комментариев в файле output.txt в текущем каталоге. Всё, что программа напечатает на экран (printf, putchar), проверка не видит.

При проверке количество пробелов, табуляций и переводов строк не важно: int x; и int x; засчитываются одинаково. Важно другое: слова, которые разделял комментарий, не должны слипнуться.
Примеры

В примерах «вход» — содержимое input.txt, «выход» — содержимое output.txt.

вход:
int main(void) /* entry point */
{
    int x = 10; // counter
    return x / 2;
}
выход:
int main(void)
{
    int x = 10;
    return x / 2;
}

вход:
printf("/* not a comment */ // neither is this\n"); // but this is
char q = '"'; /* quote in a char */ char s = '\'';
выход:
printf("/* not a comment */ // neither is this\n");
char q = '"';   char s = '\'';

вход:
int/**/a = b /*/ still a comment */ / c; /** stars **/
выход:
int a = b   / c;

Замечания

Файлы открываются так:

FILE *in = fopen("input.txt", "r");
FILE *out = fopen("output.txt", "w");

Имена пиши ровно такие, без пути: файлы лежат в текущем каталоге. Если файл не открылся, fopen вернёт NULL, и обращение к нему уронит программу — проверь это сразу после открытия. В конце закрой оба файла через fclose: пока файл открыт, часть вывода лежит в буфере и пропадёт, если программа аварийно завершится.

Читай посимвольно, пока не встретишь конец файла: while ((c = fgetc(in)) != EOF). Переменная c должна иметь тип int, а не char: EOF — это не символ, и в char он может не поместиться. Пиши через fputc(c, out) или fprintf(out, …).

Чтобы проверить решение у себя, положи рядом с программой input.txt, запусти её и посмотри, что появилось в output.txt. Удобно взять любую свою программу на C: cp prog.c input.txt.
