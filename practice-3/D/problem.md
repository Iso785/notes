}Все буквы

Дана строка из строчных латинских букв. Найди длину самого короткого её отрезка (подстроки из подряд идущих символов), в котором встречаются все буквы, какие есть в строке.
Входные данные

Одна строка длины от 1 до 200 000. В ней только символы a…z.
Выходные данные

Одно целое число — длина самого короткого такого отрезка.
Примеры

вход:
abacaba
выход:
3

вход:
aaabbbcccaaa
выход:
5

вход:
zzz
выход:
1

Замечания

В первом примере в строке три разные буквы a, b, c, и все три есть в отрезке bac. Во втором тоже три буквы, а самые короткие отрезки со всеми тремя — abbbc и bccca.

Перебрать все отрезки не успеет: их около 2·10¹⁰. Даже если для каждого начала двигать конец, пока не соберутся все буквы, на строке вида aaa…ab каждый такой поиск дойдёт до самого конца.

Держи «окно» между двумя указателями l и r и массив cnt[26]: сколько раз каждая буква встречается в окне. Двигай r вперёд, добавляя буквы в окно. Как только в окне есть все буквы, двигай l вперёд, выбрасывая буквы из окна, пока они все ещё есть. Каждый раз, когда окно содержит все буквы, его длина r - l + 1 — кандидат в ответ. Оба указателя движутся только вперёд, поэтому всё занимает два прохода по строке.

Чтобы не пересчитывать каждый раз 26 счётчиков, храни отдельно, сколько разных букв сейчас в окне: оно меняется, только когда какой-то счётчик становится из нуля единицей или из единицы нулём.

Сколько разных букв нужно собрать, заранее неизвестно: это не всегда 26. Посчитай их отдельным проходом по строке.
