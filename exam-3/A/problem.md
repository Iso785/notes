
Доска розыска

На доске розыска участка Лос-Сантоса висят фотографии беглецов. У каждого — звёзды розыска и награда в долларах. Звёзды рисуют символами *: ** — две звезды, ***** — пять. Больше пяти звёзд не бывает.

В новости попадают только те, у кого ровно пять звёзд. Посчитай суммарную награду именно по ним.

Данные лежат в файле input.txt. Результат запиши в файл output.txt.
Входные данные

Файл input.txt в текущем каталоге. Стандартный ввод пуст: читать надо из файла.

В файле несколько строк, по одной на человека. В каждой строке сначала звёзды, потом целое число bounty:

    звёзды — одно слово из символов *, длина от 1 до 5 (* … *****); других символов в этом слове нет;
    0 ≤ bounty ≤ 100 000 — награда в долларах.

Число записей заранее неизвестно — читай, пока файл не кончится. Записей от 1 до 1000.
Выходные данные

Одно целое число — сумма наград тех, у кого пять звёзд (*****), — в файле output.txt. Если таких нет, выведи 0.

Всё, что программа напечатает на экран (printf, putchar), проверка не видит.
Примеры

В примерах «вход» — содержимое input.txt, «выход» — содержимое output.txt.

вход:
***** 500
**** 1500
***** 200
***** 2500
выход:
3200

вход:
*** 100
**** 200
выход:
0

вход:
***** 100
***** 100
***** 100
выход:
300

Замечания

В первом примере в сумму входят 500, 200 и 2500 — у всех пять звёзд. Запись **** 1500 не учитывается: четырёх звёзд мало.

Файлы открываются так:

FILE *in = fopen("input.txt", "r");
FILE *out = fopen("output.txt", "w");

Имена пиши ровно такие, без пути: файлы лежат в текущем каталоге. Если файл не открылся, fopen вернёт NULL, и обращение к нему уронит программу — проверь это сразу после открытия. В конце закрой оба файла через fclose: пока файл открыт, часть вывода лежит в буфере и пропадёт, если программа аварийно завершится.

Число строк неизвестно, поэтому читай пары, пока fscanf возвращает 2. Звёзды — это строка, не число:

char stars[8];
int bounty;
while (fscanf(in, "%s %d", stars, &bounty) == 2) {
    …
}

Число звёзд — это strlen(stars) (нужен <string.h>). Для пяти звёзд оно равно 5. В массиве должно хватить места на пять символов и завершающий \0, поэтому char stars[5] будет мало.

Пиши ответ через fprintf(out, …).

Чтобы проверить решение у себя, положи рядом с программой input.txt, запусти её и посмотри, что появилось в output.txt.
