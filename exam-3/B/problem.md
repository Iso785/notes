
Чекпоинт

На карте горит сразу несколько чекпоинтов миссии. Карл сейчас в точке (x, y). Найди ближайший чекпоинт: его номер и расстояние по прямой.

Нумерация с единицы, в том порядке, в каком чекпоинты даны во вводе. Если несколько на одном расстоянии, выбери тот, что встретился раньше.
Входные данные

В первой строке два вещественных числа x и y — координаты Карла (−1000 ≤ x, y ≤ 1000).

Во второй строке целое число n — сколько чекпоинтов (1 ≤ n ≤ 100).

В каждой из следующих n строк два вещественных числа xi yi — координаты очередного чекпоинта (−1000 ≤ xi, yi ≤ 1000).
Выходные данные

Два числа через пробел: номер ближайшего чекпоинта и расстояние до него с четырьмя знаками после запятой (%.4f).
Примеры

вход:
0 0
2
6 0
3 4
выход:
2 5.0000

вход:
1.5 2.5
1
1.5 2.5
выход:
1 0.0000

вход:
0 0
2
3 4
0 5
выход:
1 5.0000

Замечания

В первом примере до (6, 0) расстояние 6, до (3, 4) — 5, поэтому ответ 2 5.0000. В третьем оба чекпоинта на расстоянии 5 — оставляем первый.

Координаты бывают дробными, поэтому читай их в double через %lf (не %f — %f в scanf предназначен для float). Печатай через %.4f.

Для sqrt нужен заголовок <math.h>. Обновляй ответ, только если новое расстояние строго меньше текущего лучшего — тогда при равенстве сохранится меньший номер.
