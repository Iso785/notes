
Кубическое уравнение

Найдите корень уравнения

x³ + a·x = b.

При a ≥ 0 функция f(x) = x³ + a·x строго возрастает, поэтому корень всегда существует и ровно один. Формулу Кардано использовать не нужно: найдите корень методом деления отрезка пополам (бисекцией).
Входные данные

В единственной строке два вещественных числа a и b, заданных не более чем с тремя знаками после запятой:

    0 ≤ a ≤ 1000;
    −10⁹ ≤ b ≤ 10⁹, b ≠ 0.

Выходные данные

Одно число — корень x с шестью знаками после запятой (%.6f). Ответ должен быть верен в шестом знаке, поэтому цикл бисекции нужно вести достаточно долго.
Примеры

вход:
0 8
выход:
2.000000

вход:
1 2
выход:
1.000000

вход:
0 -27
выход:
-3.000000

вход:
10 1
выход:
0.099900

Замечания

Корень лежит на отрезке [−1000, 1000]: при x = 1000 уже x³ = 10⁹ ≥ b, а a·x ≥ 0. На концах отрезка f(−1000) − b < 0 < f(1000) − b.

Идея: пока отрезок [l, r] длиннее допустимой погрешности, берём середину m = (l + r) / 2; если f(m) < b, корень правее — l = m, иначе r = m.

Типичные ловушки:

    искать только на [0, …] — при b < 0 корень отрицателен;
    останавливаться по условию |f(m) − b| < eps: при малых a функция вблизи нуля очень плоская, и маленькая невязка не значит маленькую ошибку в x;
    останавливаться слишком рано (фиксированные 20 шагов дадут погрешность порядка 10⁻³);
    ждать r − l == 0 или r − l > 1e-18: у double соседние числа около единицы отличаются на ~10⁻¹⁶, и цикл не закончится никогда. Проще всего сделать фиксированные 100 итераций;
    float не вмещает шесть знаков после запятой при корне порядка сотен.
